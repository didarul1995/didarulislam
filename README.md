# Didarul Islam, Ph.D. | Academic website

Plain HTML, CSS, and JavaScript. No build step.

## Files

- `index.html` page content
- `styles.css` design, light and dark themes
- `script.js` publications and filters, section highlighting, theme toggle
- `assets/img` portrait and research figures
- `assets/cv` downloadable CV

## Publish on GitHub Pages

1. Create a repository named `<your-username>.github.io`.
2. Upload everything inside this folder, including `assets` and the `.nojekyll` file.
3. Settings, then Pages: Deploy from a branch, `main`, `/ (root)`, Save.
4. The site goes live at `https://<your-username>.github.io` within a minute or two.

## Updating

- Add a publication: edit the `PUBS` list near the top of `script.js`. Counts, filters, and the chart update automatically.
- Replace the CV: overwrite `assets/cv/Didarul_Islam_CV.docx` with the same file name.
